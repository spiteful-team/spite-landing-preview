About the engineО движке

Agent-native, from the first lineНативно агентный с первой строки

SPITE is built for AI agents. Everything a person can do in the editor, an agent can do through the control protocol, and runtime state answers queries as JSON. The agent builds scenes, writes game logic in C++ modules that reload while the game runs, and reads back what it changed.SPITE сделан для ИИ-агентов. Всё, что человек делает в редакторе, агент делает через управляющий протокол, а состояние рантайма отвечает на запросы в JSON. Агент собирает сцены, пишет игровую логику в C++-модулях, которые перезагружаются прямо в запущенной игре, и читает результат своих правок.

Data-oriented ECS and GPU-driven Vulkan rendering: the GPU culls and builds its own draws, and a scene that isn't changing costs nothing.Ядро быстрее и производительнее любого конкурента на несколько порядков.
